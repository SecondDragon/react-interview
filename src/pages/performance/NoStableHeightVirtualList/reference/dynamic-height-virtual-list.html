Dynamic Height Virtual List · 核心概念、算法与实现要点

核心策略：先渲染 → 后测量 → 动态纠偏。每个 item 先用 defaultItemHeight 预估占位，渲染后由 ResizeObserver 监听真实高度，更新位置缓存并平移后续项；同时通过空间分桶把可见项查找从 O(N) 降到近似 O(1)。

一、数据结构与状态

ItemPosition

{
  index: number;   // 数据索引
  top: number;     // 距离容器顶部偏移
  height: number;   // 真实/预估高度
  bottom: number;  // top + height
}

单个 item 的位置快照，是整棵“高度树”的最小单元。

useSizeMeasurer 状态

  • positionsRef：缓存所有 item 位置。
  • totalHeight：Spacer 总高度，触发 React 渲染。
  • measureVersion：版本号，通知虚拟化引擎重建索引。

二、核心算法

1. 高度更新与平移

pos.height = measuredHeight
pos.bottom = pos.top + measuredHeight

for i = index + 1 .. N:
  positions[i].top = positions[i-1].bottom
  positions[i].bottom = positions[i].top + positions[i].height

totalHeight = positions[N-1].bottom

2. 空间分桶（Chunk Map）

chunkSize = 800
startChunk = floor(top / chunkSize)
endChunk = floor(bottom / chunkSize)

for c = startChunk .. endChunk:
  chunksMap[c].add(dataIdx)

// 检索：
startChunk = floor((scrollTop - overscan) / chunkSize)
endChunk = floor((scrollTop + viewportHeight + overscan) / chunkSize)

四、关键代码片段

ResizeObserver 监听与测量

useEffect(() => {
  const el = itemRef.current;
  if (!el) return;

  const observer = new ResizeObserver((entries) => {
    for (const entry of entries) {
      if (entry.target === el) {
        onMeasure(index, el);
      }
    }
  });

  observer.observe(el);
  return () => observer.disconnect();
}, [index, onMeasure]);

只更新后续项的平移算法

const updateItemHeight = (index, height) => {
  const pos = positionsRef.current[index];
  if (!pos || pos.height === height) return;

  pos.height = height;
  pos.bottom = pos.top + height;

  for (let i = index + 1; i < positionsRef.current.length; i++) {
    positionsRef.current[i].top = positionsRef.current[i - 1].bottom;
    positionsRef.current[i].bottom =
      positionsRef.current[i].top + positionsRef.current[i].height;
  }

  const last = positionsRef.current[positionsRef.current.length - 1];
  setTotalHeight(last ? last.bottom : 0);
  setMeasureVersion(v => v + 1);
};

空间分桶检索

const visibleIndices = useMemo(() => {
  if (viewportHeight === 0) return [];

  const startChunk = Math.floor((scrollTop - overscan) / chunkSize);
  const endChunk = Math.floor((scrollTop + viewportHeight + overscan) / chunkSize);

  const indicesSet = new Set<number>();
  for (let c = startChunk; c <= endChunk; c++) {
    const chunk = chunksMap.get(c);
    if (chunk) chunk.forEach(idx => indicesSet.add(idx));
  }

  return Array.from(indicesSet).sort((a, b) => a - b);
}, [chunksMap, scrollTop, viewportHeight, overscan, chunkSize]);

五、性能优化清单

计算层

  • O(1)Chunk Map 空间分桶，替代全量遍历
  • 增量高度变化只平移后续项
  • 版本号measureVersion 触发最小范围重建

渲染层

  • GPUtranslate3d 合成层定位
  • 裁剪只渲染可见 + overscan 项
  • 稳定Spacer 撑开真实滚动高度

事件层

  • rAFrequestAnimationFrame 节流滚动
  • 快照同步读取 scrollTop，避免事件回收空指针

加载层

  • IOIntersectionObserver 监听触底哨兵
  • 加锁isLoading / hasMore 防并发请求

六、生产注意

  • 预估高度：贴近真实值可减少首屏修正次数。
  • Key 选择：支持删除/排序时改用稳定唯一 id，而非索引。
  • 浏览器兼容：ResizeObserver / IntersectionObserver 需要 polyfill 或 SSR 兜底。
  • 大数据量：positions 随数据线性增长，可考虑只缓存已测量项。
  • 图片未知：最好由后端返回图片尺寸，减少 ResizeObserver 修正。

七、面试金句

  • “不定高虚拟列表的本质矛盾是：滚动定位需要知道高度，但高度往往在渲染后才能拿到。”
  • “我们用‘预估高度 + ResizeObserver 事后纠偏’来化解这个矛盾，先让列表能滚，再让它滚得准。”
  • “空间分桶把纵向空间按 800px 分桶，检索复杂度从 O(N) 降到近似 O(1)。”
  • “用 translate3d 把定位从 Layout 层下放到 Composite 层，只做位图移动，不重新布局。”
