<Typography.Paragraph type="secondary">
  完全版 throttle 对齐 lodash 语义：提供 <Typography.Text code>cancel</Typography.Text> / <Typography.Text code>flush</Typography.Text> API，并正确处理返回值。
</Typography.Paragraph>

## 一、完整控制 API

<Typography.Paragraph>
  在复杂版中，一旦设置了定时器就无法主动取消。完全版补充了：
</Typography.Paragraph>

- **cancel**：取消待执行的 trailing 回调，并重置状态。
- **flush**：立即执行待执行的 trailing 回调。

<Typography.Paragraph>
  这两个 API 在组件卸载、路由跳转等场景中非常重要，可避免内存泄漏或无效的异步回调。
</Typography.Paragraph>
